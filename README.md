# Cross-Instance Layer Drag (QGIS plugin)

Keeps layer IDs and copies memory-layer features when dragging layers between two running QGIS instances. QGIS 3.22 – 4.x, English and Hungarian UI.

*Megőrzi a layer ID-kat és átmásolja a memóriarétegek adatait, ha két futó QGIS-példány között húzol át rétegeket.*

## Install

Download `qgis_cross_instance_drag.zip` from the [latest release](https://github.com/danzig666/qgis_cross_instance_drag_plugin/releases/latest), then in QGIS: **Plugins → Manage and Install Plugins → Install from ZIP**. Enable it in **both** QGIS instances.
